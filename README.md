# 🧠 SQL Projects Portfolio

A growing portfolio of SQL projects focused on data analysis, schema design, query optimization, and reporting. This repository includes standalone scripts, sample datasets, and real-world use cases — built using PostgreSQL, MySQL, SQLite, and Oracle SQL.

## 🚀 Purpose

This repository serves as a central hub for my SQL development work. Each project explores practical data tasks such as querying, joining, aggregating, and designing relational schemas — all with a focus on clarity, performance, and real-world relevance.

## 🧰 Technologies Used

- SQL (PostgreSQL, MySQL, SQLite, Oracle SQL)
- Relational schema design
- Aggregate functions and joins
- Subqueries and CTEs
- Indexing and performance tuning
- Sample datasets (CSV, JSON, etc.)

## 📁 Project Structure

Each folder represents a standalone project and includes:
- `README.md` – Project overview and usage
- SQL scripts (`.sql`)
- Sample datasets (`.csv`, `.json`)
- Output files or screenshots (if applicable)
